# Ones Servitude — Game Knowledge Base

Everything about **Ones Servitude**, a co-op, session-based roguelike action RPG on Roblox (Luau): the concept, the lore, the characters, weapons, items, enemies and how the systems work.

This repo is the **design reference**, not the code. The code lives in the two Roblox Studio places. When the game and this repo disagree, the game wins. Fix the doc when that happens.

> **The pitch:** You own *Souls* (characters) and *Weapons* permanently. You take one Soul and one matching weapon into a run through the North Forest. Along the way you build a temporary set of charms, level up, and fight toward the bosses. The build dies with the run; the collection stays.
