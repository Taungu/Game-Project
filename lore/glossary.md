# Glossary

Game terms (mechanics and lore) in one place. Lore details: [world.md](world.md).

| Term | Meaning |
|---|---|
| **Affinity** | A weapon family (Heavy, Medium, Light, Conjurer, Artillery, Gauntlet). A Soul can only equip weapons of its own affinity. |
| **Affinity Stat** | The one stat a class grows extra on Mastery levels (Raam: PhysDmg; Bella: Phys+Magic; Zumin: Health; Hayut: Magic; Fahlon: none yet). |
| **Ambush** | PVP event when both teams land on the same path. They're locked in until one team is wiped. |
| **Beacon** | Permanent saved data (ownership). |
| **Charm** | An in-run item on the 6-slot hotbar. Tiers 1–3. |
| **Convoke** | The Lobby gacha. "Call" = 1 pull, "Call 10" = 10 pulls. |
| **Core Residue / Core Essence** | The white essence sparkle of a Soul (Character Page); in lore, a "second heart". |
| **Deceased** | Common Infected enemy: corpses animated by the ill Father Tree's roots. |
| **Embracer(s)** | The Embracer is the intro figure; Embracers are his followers (PVP Team A). |
| **Embracing Flush** | The bar where the player wakes up (the Lobby). |
| **Essence** | Magic/life force. In-game, the ability resource pool (like mana) and the EXP orbs enemies drop. |
| **EventAnchor!** | The part on each path where its random event spawns. |
| **Hemorrhage** | A status amplifier that turns Bleed into a damage-storing burst (Luther). |
| **Host** | An Infected enemy: a person turned by the roots. A player whose Infestation fills becomes one. |
| **Infected** | The enemy category born of the ill Father Tree (Deceased, Host). |
| **Infestation** | A hidden meter that Infected hits fill. Full = death and turning into a Host (Story only). |
| **Inner Core** | The Lobby's Character Page (Soul tab and Weapon tab). |
| **Kleilev** | A weapon forged of steel of essence. |
| **Mastery level** | In-run levels 5/10/15/20. A bigger bonus plus the Affinity Stat kicker. Not the same as Soul Mastery. |
| **Soul Mastery** | A Soul's own permanent 0–10 progression from Story runs ([soul-mastery](../systems/soul-mastery.md)). |
| **Morale** | A stacking party-wide stat penalty for fleeing fights (–10% per stack, max 5). |
| **Named Boss** | A boss that can only be met once. |
| **Navats / Seedlings** | The faction opposing the Embracers (PVP Team B); Seedlings are its members. |
| **Opharim** | A Cleanser's guardian angel that casts spells from written glyphs ([its language](world.md#the-opharims-language)). |
| **OverStatus** | Status effects that sit on top of movement control (Bleed, Blind, Slow, Vulnerable…). |
| **Path / Node** | One walkable segment of the run (StartOfPath → EndOfPath). |
| **Safe Haven** | A rest node every 5 paths: heal zone and Finn the craftsman. |
| **Silver** | Run currency (resets each run). Not the same as the SilverOre material. |
| **Soul** | A character (what Convoke and the Character Page call classes). |
| **Stagger** | A universal meter. When it fills, the target is interrupted and locked out briefly. |
| **Thorn Marks** | IllThorn slice marks that ThornBurst consumes. |
| **True damage** | Ignores resistances and damage reduction. Only tier-3 items and special moves deal it. |
| **Wanderer** | How NPCs address the player. |
